# A & A Lawn & More

Buildless one-page website. All deployable files are in `dist/`. Brand: evergreen #173F35, cream #F4F1E7, citron #D4E76C, sage #A9B7A0, clay #BC674B. Owner-supplied project photography and the approved logo are included.

## Quote behavior

Three-step form validates required services, address, ZIP, name, US phone number, schedule and project details. Optional email, access notes and photo album URL. Review builds a URL-encoded SMS draft to both +17743652080 (Aaron) and +15085098320 (Alvin). The visitor must review recipients and tap Send in their messaging app. This site does not automatically send SMS, store inquiries or confirm delivery. Multi-recipient handling varies by OS/app, so copy and separate-recipient links are available. Photos are attached in the messaging app or shared with an album URL; there is no misleading file upload control. Browser QA cannot verify native phone messaging delivery. Test on the target iOS/Android phones before public launch. Automatic server-sent messages would require a separately configured SMS provider.
